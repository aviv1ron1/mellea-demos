This demo application is a real-time voice assistant built around a single audio-enabled Granite Switch model. Audio from the user's microphone flows through WebRTC into a processing pipeline. Voice activity detection segments the user's speech into turns, and each turn's audio is sent as an audio attachment to one Granite Switch model that both transcribes the speech and generates the answer in a single request — there is no separate speech-to-text server. The model's text answer is streamed sentence by sentence into a local Kokoro text-to-speech stage for low-latency synthesis, and the resulting audio streams back to the user's browser over WebRTC.

The result is an end-to-end voice conversation from one model load: a single Granite Switch checkpoint handles both understanding the spoken question and generating the response, with its embedded LoRA adapters available on audio requests exactly as on text, and local Kokoro TTS turning the answer back into speech. Loading just one model keeps deployment simple — one checkpoint, one inference server, audio and text on the same endpoint.
